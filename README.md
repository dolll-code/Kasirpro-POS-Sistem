# Kasirpro-POS-Sistem
Aplikasi kasir dan manajemen toko berbasis web menggunakan Laravel, dengan fitur penjualan, inventaris, pembelian, supplier, retur, pengeluaran, dan laporan keuangan. | A web-based Point of Sale (POS) and Retail Management System built with Laravel, featuring sales, inventory, purchasing, suppliers, returns, expenses, and financial reports.
